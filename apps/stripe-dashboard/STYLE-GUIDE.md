# Stripe Dashboard / Checkout — 风格总指南

> 用途：表单、结账、后台壳参考。Dashboard 深页本批未登录，仅 login + 公开 Checkout 示例。  
> 截图：`apps/stripe-dashboard/<screen>/`

---

## 一、产品整体 DNA
**支付安全感表单天花板**：字段间距、错误态、步骤感、信任微文案。Dashboard 为左导航工作台；Checkout 为居中卡片结账。

### 原则
1. 表单标签清晰、帮助文案弱化但不消失。
2. 主按钮单一高对比；次要操作为文字/描边。
3. Checkout：卡片居中、品牌区克制、输入框大触控。
