# v0 (Vercel) — 风格总指南（STYLE-GUIDE）

> 用途：还原 v0.dev / v0.app 生成式前端工作台。  
> 平台：Web · 物理 4K。  
> 截图：`apps/v0-web/<screen>/`。

---

## 一、产品整体 DNA

### 一句话定位
**Vercel 黑白极简 × 对话生成 UI × 右侧/下方预览画布**；营销壳与工作台可同域切换（v0.dev → v0.app）。

### 设计原则
1. 高对比黑白，少彩色。
2. 左/中对话提示，右预览或全宽画布。
3. 组件语言贴近 Vercel Dashboard（细边框、小圆角、等宽感）。

### 色板 Token（约值）
| Token | 约值 | 用途 |
|-------|------|------|
| `--bg` | `#000` / `#FAFAFA` | 深/浅主题 |
| `--border` | `#333` / `#EAEAEA` | 分割 |
| `--accent` | `#0070F3` 或纯白反色按钮 | CTA |
| `--text` | 近白/近黑 | 主文字 |

### 字体
- Inter / Geist；代码区等宽。

### 组件通则
- Prompt 输入 + 生成；项目列表；预览 iframe/画布。

### 可还原总配方
1. 极简顶栏 + 提示列 + 预览。
2. 少装饰，靠对齐与对比。

### 反例
- 暖纸 Claude 风或 Material 光晕。
