# Stripe Marketing — 风格总指南（STYLE-GUIDE）

> 用途：还原 stripe.com 营销站的排版节奏与产品叙事。  
> 平台：Web · 本批截图为活动桌面 1920×1200（ToDesk 主屏；4K 未进拓扑）。  
> 截图：`apps/stripe-web/<screen>/`

---

## 一、产品整体 DNA

### 一句话定位
**大留白英雄区 + 克制蓝紫强调 + 产品叙事滚动**：表单/支付安全感的「对外门面」，不是 Dashboard。

### 设计原则
1. **英雄区居中/左齐大标题**，副文案短，主 CTA 高对比。
2. **导航克制**：Products 巨型菜单，但不喧宾夺主。
3. **章节节奏**：产品能力 → 客户证明 → 开发者入口，留白大于装饰。
4. **代码/示意图**常作为可信度元素，而非花哨插画堆砌。

### 色板 Token（约值）
| Token | 约值 | 用途 |
|-------|------|------|
| `--bg` | `#FFFFFF` / 近白 | 主背景 |
| `--text` | `#0A2540` 深蓝黑 | 标题正文 |
| `--accent` | `#635BFF` 紫蓝 | CTA / 链接 |
| `--muted` | `#425466` | 副文 |

### 可还原配方
1. `nav(logo+Products+开发者) | hero(大标题+双CTA) | section stack`。
2. 圆角中等；阴影极轻。
3. 勿用霓虹渐变盖过文案层级。

## 二、分页面说明
## home — 官网首页英雄区  
## products — Products 导航/菜单展开  
## payments — Payments 产品页叙事
