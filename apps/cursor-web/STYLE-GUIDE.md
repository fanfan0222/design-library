# Cursor Web — 风格总指南（STYLE-GUIDE）

> 用途：还原 cursor.com 官网/Agents Web 壳。  
> 平台：Web · 物理 4K。  
> 截图：`apps/cursor-web/<screen>/`。

---

## 一、产品整体 DNA

### 一句话定位
**深色开发者营销 + Agents 产品页**；cursor.com 常直接落到 `/agents`。与桌面 Cursor IDE 同品牌，但 Web 更偏落地/云 Agents。

### 设计原则
1. 深底、高对比、少装饰线。
2. 大标题 + 代码/Agent 演示模块。
3. 顶栏：产品、定价、登录/下载。

### 色板 Token（约值）
| Token | 约值 | 用途 |
|-------|------|------|
| `--bg` | `#0A0A0A`–`#111` | 主底 |
| `--text` | `#F5F5F5` | 主文字 |
| `--muted` | `#888` | 次要 |
| `--accent` | 亮绿/白按钮 | CTA |

### 字体
- 几何无衬线；代码等宽。

### 可还原总配方
1. 深色全屏营销/产品壳。
2. Agents 页作为主产品入口。

### 反例
- 浅色 ChatGPT 壳。
