# GitHub — 风格总指南

> 工程师产品默认语法：Issue/PR/Settings。  
> 截图：`apps/github-web/<screen>/`

---

## 一、产品整体 DNA
**顶栏全局导航 + 仓库上下文子导航 + 列表/Markdown 表单**。信息密度中高；链接蓝、状态用小徽章。

### 原则
1. Issues：筛选条 + 列表行（标题/标签/元信息）。
2. Settings：左分区导航 + 右危险区（红色破坏性按钮）。
3. 表单：标签上置、帮助灰字、Save 主按钮右下。

## 二、分页面
## home — 登录后首页/仪表  
## issues — Issues 列表
