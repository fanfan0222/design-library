# Grok Bot — 风格总指南（STYLE-GUIDE）

> 用途：给实现者 / 其他 AI 还原「Grok Bot 式」桌面对话产品视觉与交互气质。  
> 平台：Windows 桌面端 · 浅色 · 中英文混排。  
> 截图目录：`apps/grok-bot/<screen>/`（`shot.png` 4K 原图 + `shot-ai.jpg` AI 预览）。  
> 分析只谈 UI chrome，不复述聊天正文内容。

---

## 一、产品整体 DNA

### 一句话定位
**侧栏会话列表 + 居中对话主列 + 底栏作曲器** 的桌面 Agent 聊天壳：解约克制、浅色、轻量信息密度，偏「好看/灵性」而非工程工具面板堆叠。

### 设计原则
1. **对话优先**：主区是聊天，不是工具墙；设置、账户用浮层/模态，不抢主舞台。
2. **三区清晰**：左会话轨 / 中消息流 /（可选）右详情抽屉；分隔靠 1px 浅灰线，不用重阴影。
3. **克制配色**：大面积中性灰白；强调色只出现在发送气泡、开关、选中态。
4. **圆角友好但不玩具化**：气泡与输入框约 10–14px；模态约 12–16px；避免全圆角「糖果」按钮铺满。
5. **中文桌面原生感**：系统无衬线（Segoe UI / 微软雅黑感），字号偏 13–14px 正文，行高约 1.5–1.6。

### 色板 Token（可复用）
| Token | 约值 | 用途 |
|-------|------|------|
| `--bg-app` | `#F5F5F7` / `#F7F7F8` | 窗口底层浅灰 |
| `--bg-sidebar` | `#FFFFFF` 或略灰 | 会话列表底 |
| `--bg-chat` | `#F7F7F8` | 消息区底 |
| `--bg-surface` | `#FFFFFF` | 卡片/模态/气泡底 |
| `--border` | `#E5E5EA` | 栏间分割、输入框描边 |
| `--text-primary` | `#1A1A1A` / `#222` | 标题与正文 |
| `--text-secondary` | `#8E8E93` | 预览、时间、说明 |
| `--accent` | 深蓝绿 / 墨绿 `#0D5C5C`–`#1A6B6B` 系 | 用户气泡、关键 CTA |
| `--accent-soft` | 浅蓝灰 | 选中侧栏行、hover |
| `--danger` | `#E5484D` 系 | 退出/危险操作 |
| `--shadow-modal` | `0 12px 40px rgba(0,0,0,.18)` | 设置模态抬升 |

### 字体与排版
- 无衬线；中英混排基线对齐。
- 侧栏会话标题：14px medium；预览一行 12px secondary。
- 助手正文：14–15px regular，行高宽松；代码路径用等宽 + 浅底高亮。
- 设置分组标题：13–14px semibold；说明 12px secondary。

### 组件通则
- **侧栏项**：左圆形彩头像 + 双行文字；选中浅底圆角条。
- **用户气泡**：实心强调色 + 白字，右对齐。
- **助手消息**：无重气泡或极浅底，左对齐；下方小灰图标（复制/重试）。
- **作曲器**：底栏圆角矩形，左 + / 附件，右发送；可带「连接应用」等次级按钮。
- **模态设置**：居中对话框，左分区导航 + 右表单行（左文案右控件）。
- **菜单/搜索**：贴锚点的白底 popover，轻阴影，列表项中等密度。

### 交互气质
- 密度：侧栏中高、主区中低留白。
- Hover：浅灰底；选中：浅强调底或左侧色条。
- 动效：短、克制；模态出现 + 背景压暗即可。
- **像**：Grok Bot / Agent Chat 对话壳。  
- **不像**：Codex 重工具侧栏堆叠、IDE 多面板、阿里工程风厚重工具栏。

### 可还原总配方
1. 搭 `sidebar(~240–280px) | chat(flex)`，消息列 `max-width ~720–860px` 居中。
2. 铺中性灰白 + 1px 分割。
3. 做会话列表、气泡、底栏作曲器。
4. 设置做成居中双栏模态，勿做成全页设置中心（那是 Codex 路线）。
5. 功能可省略（电脑操控、用量账单），骨架与气泡气质必须像。

### 反例（整产品级）
- 侧栏塞满工具图标轨 + 第二层项目树（更像 Codex）。
- 主区满屏表格/文件树抢戏。
- 高饱和渐变背景、玻璃拟态滥用。
- 直角硬边 + 粗描边「企业后台」感。

## 二、分页面说明

## main — 主聊天
- **布局**：左会话列表 + 中消息流 + 底作曲器；无右侧抽屉。
- **要点**：用户深绿气泡 vs 助手纯文本；消息列居中留白；侧栏头像彩色圆点作视觉锚。
- **必须像**：双栏对话壳、底栏输入、轻分割。
- **可省略**：真实会话内容、连接应用按钮文案。

## new-chat-empty — 新建空对话
- **布局**：仍双栏；主区空态，顶部「收件人」选择条 + 底作曲器。
- **要点**：空态克制，不堆插画；焦点在收件人与输入。
- **必须像**：空画布 + 顶栏选择器 + 底输入。
- **可省略**：具体联系人数据。

## details-info-tab / details-media-tab / details-computer-tab — 右侧详情抽屉
- **布局**：三栏：侧栏 | 聊天 | 右抽屉（约 22–28%）；抽屉内 Tab（详情 / 资料库 / 电脑）。
- **info**：资料卡片、成员/元信息列表。
- **media**：文件/媒体网格或按日期分组列表。
- **computer**：机器状态、远程桌面相关信息行。
- **必须像**：聊天不消失、抽屉从右滑入、Tab 切换。
- **可省略**：真实文件缩略图内容。

## account-menu — 账户菜单
- **布局**：锚在左下账户按钮上方的窄 popover。
- **要点**：设置 / 反馈 / 锁定 等列表项；轻阴影白底。
- **必须像**：贴锚点上浮菜单，不占全屏。

## sidebar-search — 侧栏搜索
- **布局**：搜索触发的 overlay/palette，覆盖或贴在侧栏区域。
- **要点**：结果分组列表；关键词可高亮；密度高于主聊天。
- **必须像**：命令面板气质，而非独立整页搜索站。

## settings / settings-computer / settings-usage / settings-updates — 设置模态族
- **布局共性**：居中模态 + 背景压暗；左窄分区导航 + 右表单。
- **settings（通用）**：账户卡（头像/邮箱）+ 外观/系统开关与下拉；控件右对齐。
- **settings-computer**：电脑相关路径、权限、连接状态行。
- **settings-usage**：用量/账单进度条或用量数字 + 管理按钮。
- **settings-updates**：版本号、检查更新、清理类危险操作（红字/红按钮克制使用）。
- **必须像**：对话框而非全页；左导航图标+文字；行式「标题+说明 | 控件」。
- **可省略**：真实邮箱展示（外发打码）；具体套餐文案。

## 三、与对照族差异（提醒）
| | Grok Bot | Codex 桌面 |
|--|----------|------------|
| 导航 | 单侧会话列表 | 图标轨 + 会话/项目侧栏 |
| 设置 | 居中模态 | 全页设置中心 |
| 气质 | 对话/克制 | 构建工具/功能面更全 |
